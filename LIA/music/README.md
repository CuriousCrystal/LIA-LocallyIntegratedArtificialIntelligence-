# Her music

Drop audio files here and she'll play them by number.

**Supported:** `.mp3`, `.wav`, `.flac`, `.ogg`, `.m4a`, `.aiff`

```
"Lia, what music do you have"    → she reads out the list
"play number 1"  /  "play song 3"  /  "play the second song"
"play Fireflies"                 → by name, if the filename matches
"stop the song"
```

Numbering follows filename order, so **number 3 means the same thing tomorrow
as it does today**. Naming files `01 Something`, `02 Something else` keeps that
order obvious and stable.

## How this differs from "play music"

Two separate things, easy to confuse:

- **This folder** is music she *owns*. She can start a track from nothing.
- **"play music" / "pause"** is a remote control over whatever *another* app
  (Spotify, a browser tab) already has loaded. She can't start anything there,
  only resume what's sitting paused.

She plays through her own audio, so no window opens and nothing else is needed.
While she's speaking the music drops to a murmur rather than stopping, and
comes back up when she's done.
