# Her memory

Drop `.txt` files here -- Notepad or anything else that saves plain text.
Every non-blank line of every file becomes one thing she knows about you.

She reads this folder fresh each time it's needed (a change is picked up
without restarting her), and never writes to it. If something should be
remembered, you write it here yourself; nothing she says can come from
anywhere else.

`"Lia, what do you remember"` / `/notes` reads it all back to you.
`/notes reload` forces a fresh read if a change doesn't show up on its own.
